This is a project for a wordpress plugin which visually and functionally shows the same navigation menu to the user of https://www.mamanvoyage.com/
The menu is currently generated by the UberMenu plugin. The UberMenu plugin has a lot of unused functionality.
The goal of the plugin is to generate visually and functionally identical output in a much slimmer package.
All of the menu should be hardcoded directly in the plugin instead of using register_nav_menus / wp_nav_menu.
Only look up the current language ( / for French, /en/ for English, /de/ for German), the rest of the menu is completly defined directly as html/css in the plugin instead of being dynamically generated. Format the php such that updating the menu is simple when adding or removing menu items. 

Be proactive and inventive - slim down html, js and css where possible without impacting visual output

### Safety and permissions

Allowed without prompt:
- read files, list files, write files, get any file (html, css, js) from http://www.mamanvoyage.com/

Note: proactively suggest installation of tools which would help with your task for installation.
